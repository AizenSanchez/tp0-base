## Ejercicio 3: Validacion del Echo Server con netcat

### Objetivo

Verificar el correcto funcionamiento del servidor echo enviando un mensaje y comprobando que la respuesta recibida sea exactamente la misma.

### Ejecucion

Desde la raiz del proyecto:

```bash
./validar-echo-server.sh
```

### Criterio de validacion

- Si la prueba es exitosa, se imprime:

```text
action: test_echo_server | result: success
```

- Si la prueba falla, se imprime:

```text
action: test_echo_server | result: fail
```
